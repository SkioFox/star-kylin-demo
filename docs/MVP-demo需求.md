# MVP Demo 需求拆解

> 版本 v0.3 ｜ 2026-07-21 ｜ **独立 demo,不依赖也不改动 REQUIREMENTS/ADR/design 分析**
> 目标平台:**麒麟操作系统真机**良好运行;登录/权限全部 **mock**。

## 1. 目标可见结果(验收即演示)
1. **Mock 登录成功后进入工作台**。
2. **至少两个 Mock 角色显示不同菜单**(切换角色 → 菜单随权限变化)。
3. **内嵌一个指定 Web 页面**,支持**加载、刷新、错误提示**。
4. **从白名单拉起一个指定麒麟应用**;**未安装时提示明确**。
5. **K 线示例**:蜡烛图、缩放、平移、十字线,数据为 **Mock 行情**。
6. **在指定麒麟真机上启动、切换、操作无明显卡顿**。

## 2. 安全红线(demo 也必须保留,不得为省事去掉)
- **S1** QProcess **只能启动清单中的固定程序**,**禁止拼接 Shell 命令**(参数固定/白名单,不经 shell)。
- **S2** WebView **仅允许指定 URL/Origin**(白名单,越界拦截)。
- **S3** Mock 登录**不得使用真实银行账号或凭证**(纯假数据)。
- **S4** K 线**只用 Mock 数据**(不连真实行情)。
- **S5** 无实际需求时,**不实现 JSBridge 的文件/设备/凭证能力**(最小暴露,能不做就不做)。

## 3. 模块拆解

| 模块 | 内容 | 对应结果 |
|---|---|---|
| **M1 门户外壳** | Qt/QML 原生窗口:顶栏 + 菜单/工作台 + 标签容器;麒麟真机正常启动/渲染/交互 | 1、6 |
| **M2 登录+权限(mock)** | mock 登录页(假账号)→ mock 接口返回角色与菜单权限 → 工作台按角色渲染菜单;**≥2 角色** | 1、2 |
| **M3 内嵌 web** | 标签内 QtWebEngine 加载**指定 URL**;工具条含**刷新**;加载失败显示**错误提示**;仅白名单 Origin(S2) | 3 |
| **M4 拉起原生应用** | 从**清单白名单**用 QProcess 拉起指定麒麟应用;**固定程序+固定参数,不过 shell**(S1);未安装 → **明确提示** | 4 |
| **M5 K 线示例** | 平台内模块页:QtWebEngine 加载**本地打包的 web 图表页**(klinecharts/ECharts),蜡烛图 + 成交量 + **缩放/平移/十字线**,**mock 数据**(S4) | 5 |

## 4. 技术决策(已定)
- **开发语言:C++/QML**(与产品一致,demo 可演进为 M0 骨架)。
- **K 线实现:内嵌 web 图表库**(klinecharts/ECharts,本地打包页 + mock 数据喂入)。即 M5 复用 QtWebEngine,加载本地图表页。

### 仍待确认(小,不阻塞开工)
1. **拉起目标**:用哪个麒麟自带应用作示例(默认:计算器 `kylin-calculator` 或文件管理器)。
2. **内嵌页面**:指定哪个 URL(默认:先用一个本地/公开占位页,后替换为指定页)。

## 5. 清单驱动(贯穿 M2–M4,落地安全红线)
一份 `manifest`(json)是所有白名单的唯一来源:
```jsonc
{
  "roles": { "roleA": ["appWeb","appKline"], "roleB": ["appWeb","appNative"] },
  "modules": [
    { "id":"appWeb",    "type":"web",    "url":"https://<指定>",        "allowedOrigins":["https://<指定>"] },
    { "id":"appNative", "type":"native", "exec":"/usr/bin/<固定程序>", "args":[] },
    { "id":"appKline",  "type":"kline" }
  ]
}
```
- `type:web` → 仅 `allowedOrigins` 放行(S2)。
- `type:native` → 仅 `exec` 固定路径 + 固定 `args`,QProcess 不经 shell(S1)。
- 角色→模块映射驱动菜单(结果 2)。

## 6. 组件结构(建议)
```
demo/                 C++/QML 工程(CMake)
  shell/              门户外壳(窗口 + 菜单 + 标签容器)
  mock-api/           mock 登录/权限(本地桩,假数据 S3)
  web-kline/          本地 web 图表页(klinecharts/ECharts)+ mock 行情(S4)
  manifest.json       角色/模块/白名单(唯一可信源)
```

## 7. 诚实边界
- 登录/权限/行情均 mock,**不证明**真 CAS/权限中心/行情集成。
- 以"良好运行 + 效果可演示 + 无明显卡顿"为准,**不做**性能量化/国密/打包结论(见 M-1)。
- 原生拉起为**启动器式**(独立窗口),非嵌入 Tab(嵌入受 Wayland 限制,见分析文档)。
