# ADR-0002 目标架构:ARM64 + x86_64 双架构

- 状态:已接受
- 日期:2026-07-21

## 决策
同时支持 **ARM64(飞腾/鲲鹏)** 与 **x86_64**,ARM64 为主战场。

## 理由
行内 PC 含大量国产 ARM 芯片,信创迁移以 ARM64 为主;x86_64 兼容存量常规 PC。

## 影响与约束
- 第三方库须在飞腾/鲲鹏上有可用构建;无预编译包的依赖需自行交叉编译或替换。
- CI 须双架构构建与打包,`.deb` 分 arch 产物。
- 性能指标须**分架构**给出(飞腾 D2000 与某 x86 基线分别锁定,见 REQUIREMENTS §5)。

## 待确认
- 具体飞腾/鲲鹏型号基线(至少一款作为性能基准机)。
- 是否需要龙芯(LoongArch)等其他国产架构 —— 当前假设否。
