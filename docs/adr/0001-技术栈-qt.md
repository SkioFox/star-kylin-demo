# ADR-0001 技术栈:Qt/QML

- 状态:已接受(用户在需求沟通中选定)
- 日期:2026-07-21

## 决策
门户外壳采用 **Qt/QML (C++)**,web 容器采用 **QtWebEngine**。

## 背景与理由(修正评审第 4 点:不过度论证)
- 麒麟官方 SDK 即 Qt 生态,国产化适配资料与支持最完整。
- 外壳、原生组件、系统集成层用 Qt 原生实现,获得原生级交互体验。
- **须澄清的边界**:QtWebEngine 内部是 Chromium 多进程架构,**web 子应用的页面渲染性能主要取决于 Chromium/页面/网络,不因选 Qt 而更快**。Qt 的"原生"红利体现在**外壳与原生组件**,不体现在 web 子应用页面本身。
- 不做"唯一能兑现原生""Electron 必然达不到"这类无基准结论;若需对比,在 M-1 以真机基准测试给出数据。

## 必须前置的约束(评审补充,原文缺失)
1. **版本与安全责任**:锁定 Qt 具体版本与 QtWebEngine 对应的 Chromium 版本;明确 **Chromium CVE 的跟踪与升级责任人/周期**(银行安全要求)。
2. **授权合规**:明确采用 **商业版 or LGPL**;若 LGPL,须满足**动态链接**、可替换库、随交付附**第三方许可证清单**等义务。参考 Qt Licensing 官方说明。

## 待确认
- Qt 版本、QtWebEngine/Chromium 版本(M-1 核定,随 V10 镜像)。
- 授权方式(商业/LGPL)与合规交付清单 —— 需与行内法务/采购确认。
