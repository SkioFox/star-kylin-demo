# 星麒业务工作台 UI 原型与功能规格

> 版本 v0.2 ｜ 2026-07-21 ｜ 状态：**修复完成，待 UI 复验**  
> 适用范围：`mvp-demo` 桌面端原型；与 [MVP-demo需求.md](./MVP-demo需求.md) 配套使用。  
> 高保真原型与 UI 图：[ui-prototype/README.md](./ui-prototype/README.md)。  
> 实施门禁：本文与高保真原型评审通过前，不进入 Qt/QML 正式实现。

## 1. 原型目标

面向银行内部员工，设计一套运行于麒麟桌面的统一业务工作台原型。首屏直接服务日常工作，不做产品宣传页：用户完成 Mock 登录后，只看到当前角色获准使用的 Web 业务、行情示例和本机应用入口。

本原型必须回答四个问题：

1. 用户如何进入并确认当前身份、环境和角色。
2. 用户如何快速找到、打开、切换授权模块。
3. Web、K 线和原生应用在加载、成功、失败时如何反馈。
4. 后续实现如何在不补猜设计细节的情况下完成验收。

## 2. 设计方向

### 2.1 视觉立场

**方向：克制、可信、业务密集的银行桌面工作台。**

- 深海军蓝只承担全局导航和身份锚点；主工作区使用冷白与浅灰，避免整屏蓝色造成压迫。
- 操作蓝表示可执行命令；金色用于品牌识别；青色补充分区识别；红、绿、琥珀色只表达明确状态。
- 页面以固定外壳、表格、工具条和状态带为主；卡片仅用于可重复的应用入口，不把每个区域都包成卡片。
- 不使用渐变、发光、玻璃拟态、装饰性光斑、超大标题和营销式插画。
- 内容区圆角不超过 `6px`；常规区域不用阴影，只有模态框可使用轻阴影建立层级。

### 2.2 标志性元素：业务状态轨道

全局顶栏下方保留一条 `32px` 高的“业务状态轨道”，持续显示：

- 当前环境：`演示环境`
- 本地 Mock：`可用`
- 行情数据：`本地数据 · 更新时间 09:30:00`
- 当前角色：`综合柜员` 或 `运营主管`

它既是原型的识别特征，也是用户判断演示状态的固定位置，不作为装饰。

### 2.3 应避免的通用模板感

- 不使用四个同尺寸统计卡作为工作台首屏。
- 不使用巨大的欢迎语挤占操作空间。
- 不把侧边栏折叠成只有图标的导航；银行业务名称必须可直接识别。
- 不用无意义的走势图填充空白；K 线只出现在行情模块中。
- 不用 Emoji 充当菜单或状态图标；实现时使用项目现有图标库或 Qt 原生图标。

## 3. 设计系统

### 3.1 色彩令牌

| 用途 | 色值 | 使用规则 |
|---|---|---|
| 深色导航 `nav-900` | `#0A2F5E` | 全局顶栏、登录品牌区 |
| 操作蓝 `primary-600` | `#0B5CAD` | 主按钮、选中项、链接、焦点环 |
| 操作蓝悬停 `primary-700` | `#084A8B` | 主按钮和可点击文本悬停 |
| 浅蓝选中 `primary-050` | `#EAF2FC` | 选中菜单背景、轻提示背景 |
| 页面底色 `canvas` | `#F4F7FB` | 工作区背景 |
| 内容表面 `surface` | `#FFFFFF` | 表格、工具条、内容面 |
| 主文本 `text-900` | `#14243A` | 标题、正文、关键数据 |
| 次文本 `text-600` | `#596B82` | 辅助信息、时间、说明 |
| 分隔线 `border` | `#D7E1ED` | 表格线、输入框、区域边界 |
| 品牌金 `accent-gold` | `#B3883E` | 品牌细线、小面积身份强调 |
| 辅助青 `accent-teal` | `#1C7F8F` | Web/行情等模块分类标识 |
| 成功 `success` | `#17805C` | 成功状态；必须同时有文字或图标 |
| 警告 `warning` | `#9A651A` | 风险、等待、部分可用 |
| 错误 `danger` | `#B63E49` | 错误、阻断；必须同时有文字或图标 |

已校验的正文对比度：白色/深色导航 `13.28:1`、白色/操作蓝 `6.67:1`、主文本/页面底色 `14.55:1`、次文本/白色 `5.45:1`、白色/成功 `4.91:1`、白色/警告 `4.94:1`、白色/错误 `5.56:1`。正文与关键控件均达到 WCAG AA；浅色状态背景必须搭配深色文字，不以颜色作为唯一信息。

### 3.2 字体与数字

- 界面字体：优先 `Noto Sans CJK SC` / `思源黑体`，回退至系统无衬线字体。
- 行情数字：优先 `Noto Sans Mono`，回退至系统等宽字体，并启用等宽数字。
- 字号层级：`12 / 14 / 16 / 20 / 24 / 32px`；正文默认 `14px`，紧凑表格可用 `13px`。
- 页面标题最大 `24px`；登录产品名可使用 `32px`，不使用营销页级超大字体。
- 字间距统一为 `0`，不随视口宽度缩放字号。

### 3.3 尺寸与布局

| 项目 | 规格 |
|---|---|
| 设计基准 | `1440 × 900`；物理分辨率验收 `1366 × 768` |
| 最低逻辑工作区 | `820 × 480`，覆盖 `1366 × 768 @ 150%` 的等效逻辑尺寸 |
| 全局顶栏 | `56px` |
| 业务状态轨道 | `32px` |
| 左侧导航 | `208px`；低宽度时可收至 `184px`，仍保留文字 |
| 标签栏 | `44px` |
| 内容边距 | 桌面 `24px`，最低宽度 `16px` |
| 间距系统 | 以 `4px` 为基数，常用 `8 / 12 / 16 / 24 / 32px` |
| 输入框/按钮 | 高度不低于 `44px` |
| 图标按钮 | `44 × 44px`，图标 `18–20px` |
| 圆角 | 输入/按钮 `4px`，应用入口 `6px`，模态框 `6px` |

固定格式区域使用明确的网格轨道、最小宽度和高度，加载文案、状态标签、悬停态不能引发布局位移。

## 4. 信息架构

```text
S01 Mock 登录
  └─ 登录成功 → S02 工作台首页
                   ├─ S03 Web 业务模块（标签内）
                   ├─ S04 K 线模块（标签内）
                   └─ S05 原生应用启动反馈（独立窗口）

任意工作台页面
  ├─ 切换已打开标签
  ├─ 返回工作台首页
  └─ 退出登录 → S01 Mock 登录
```

全局导航分为两层：左侧栏负责发现授权模块，标签栏负责切换已打开任务。两者不可混用；原生应用在系统独立窗口中打开，不伪装成标签页。

## 5. 角色与菜单

| Mock 用户 | 展示身份 | 授权菜单 | 用途 |
|---|---|---|---|
| `demoA` | 综合柜员 | 工作台、Web 业务、行情中心 | 验证 Web 与 K 线 |
| `demoB` | 运营主管 | 工作台、Web 业务、本机工具 | 验证角色差异与原生拉起 |

- 不提供登录后的“角色切换器”，避免用户绕过权限语义；演示角色通过退出后使用另一个 Mock 用户体现。
- 未授权模块不显示在侧栏、工作台入口或搜索结果中。
- 当前角色固定显示在业务状态轨道和用户菜单中。

```text
│                               │                                              │

│                               │                                              │

│  受控访问                     │  [ demoA                                  ]  │

│                               │  [ ••••••••                               ]  │
│                               │                                              │

└───────────────────────────────┴──────────────────────────────────────────────┘
```

布局与行为：

- 左侧约占 `36%`，使用深海军蓝；产品名、环境和三项可信信息直接排版，不放入卡片。
- 右侧表单最大宽度 `420px`，垂直居中；不使用悬浮登录卡。
- 用户名与密码始终有可见标签，不依赖占位符。
- 密码显示按钮使用眼睛图标，具备工具提示和可访问名称。
- 点击登录后按钮保持宽高不变，文案变为“正在登录”，并显示进度图标。
- 登录失败在密码框下方原位显示；输入框进入错误态并聚焦首个错误字段。
- 页面明确出现“Mock 演示登录”，不得产生真实网银登录的误解。

### S03 Web 业务模块

```text
┌──────────────┬───────────────────────────────────────────────────────────────┐
│ 全局侧栏     │ [工作台] [Web 业务 ×]                                       │
│              ├───────────────────────────────────────────────────────────────┤
│ Web 业务 ●   │ [←] [→] [刷新]  指定业务系统       演示来源：bank.example   │ 44
│              │ ─────────────── 页面加载进度 ─────────────────────────────── │  2
│              ├───────────────────────────────────────────────────────────────┤
│              │                                                               │
│              │                 内嵌指定 Web 页面                             │
│              │                                                               │
│              │  失败时：                                                     │
│              │  [错误图标] 页面暂时无法打开                                 │
│              │  无法连接到已授权地址。                                      │
│              │  [重新加载]                                                   │
│              │                                                               │
└──────────────┴───────────────────────────────────────────────────────────────┘
```

- 后退、前进、刷新使用标准图标按钮；鼠标悬停显示工具提示，禁用态仍保留固定尺寸。
- 工具条显示业务名称和来源域，不开放任意地址输入；高保真原型使用“演示来源”，正式实现仅显示实际校验结果。
- 加载期间在工具条下方显示 `2px` 进度条；完成后消失但不改变内容区起始位置。
- 加载失败显示原因摘要和“重新加载”，外壳与其他标签仍可操作。
- 未授权 Origin、重定向或弹窗被阻止时，用通知条说明“已阻止打开未授权地址”，不得在容器内继续加载。
- HTTPS/来源标识只陈述实际状态，不伪造安全认证或安全背书。

- 图表是页面主区域，不放入装饰卡片；价格区与成交量区共享横轴。
- 周期使用分段控件；“重置视图”是明确命令按钮。
- 鼠标滚轮缩放、拖拽平移、悬停十字线；操作不改变工具条和整体布局尺寸。
- 红绿语义同时用 `+/-`、文字和蜡烛空实/边框差异表达，不能只靠颜色。
- 十字线浮层显示日期、开高低收、成交量；同时在图表下保留当前点的表格化数据，便于键盘与低视力用户读取。
- 数据源固定显示“MOCK 数据”；断网后仍完整可用。
- 无数据时保留图表区域尺寸，显示“暂无演示行情数据”和“重新加载数据”。

### S05 原生应用启动反馈

原生应用不占用内部标签，点击入口后依次呈现：

```text
可用 → 入口显示“正在启动…” → 启动成功通知 → 系统独立窗口出现
缺失 → 阻断模态框：“未找到指定应用” → [重新检测] [关闭]
失败 → 阻断模态框：“应用启动失败” → 原因摘要 → [重试] [关闭]
```

- 启动过程中入口禁用，避免连续拉起多个进程。
- 成功通知 `4s` 后自动消失，也可手动关闭；失败模态框不自动消失。
- 提示中可以显示应用名称，不向普通用户暴露 Shell 命令或内部堆栈。
- “重新检测”只检查清单中的同一固定路径，不搜索或尝试其他程序。

## 7. 功能规格

| ID | 优先级 | 功能 | 原型行为 | 验收要点 |
|---|---|---|---|---|
| **F01** | P0 | Mock 登录/退出 | 假用户登录、错误反馈、退出回登录页 | 明示 Mock；无真实账号；退出清会话 |
| **F02** | P0 | 角色化导航 | 两个 Mock 用户显示不同菜单和应用入口 | 未授权模块在所有入口不可见 |
| **F03** | P0 | 外壳与标签 | 工作台固定；Web/K 线可打开、切换、关闭 | 同模块单实例；状态稳定、不跳动 |
| **F04** | P0 | 内嵌 Web | 加载、后退、前进、刷新、失败重试、来源拦截 | 只允许白名单 URL/Origin |
| **F05** | P0 | 原生应用启动 | 固定入口启动、启动中、成功、缺失、失败反馈 | QProcess 固定程序/参数，不经 Shell |
| **F06** | P0 | K 线示例 | 蜡烛、成交量、周期、缩放、平移、十字线、重置 | 本地 Mock 数据；断网可演示 |
| **F07** | P0 | 统一反馈 | 行内校验、通知条、空态、错误态、模态框 | 错误可恢复；不暴露内部敏感信息 |
| **F08** | P0 | 清单驱动 | 用户、角色、模块和白名单来自只读 Manifest | 配置无效时拒绝进入工作台 |

## 8. 状态矩阵

| 对象 | 状态 | 可见反馈 | 可用操作 |
|---|---|---|---|
| 登录 | 默认 | 空表单或预置演示用户名 | 输入、显示密码、登录 |
| 登录 | 校验失败 | 字段提示 + 错误焦点 | 修正、再次登录 |
| 登录 | 提交中 | 按钮内进度 + “正在登录” | 禁止重复提交 |
| 登录 | 认证失败 | 表单内统一错误 | 修改凭证、重试 |
| Web | 加载中 | 进度条；页面区保留 | 停留、切换标签 |
| Web | 可用 | 指定页面 + 来源域 | 后退、前进、刷新 |
| Web | 失败 | 原因摘要 + 重新加载 | 重试、关闭标签 |
| Web | 越界 | 拦截通知；原页面保持 | 关闭通知、继续原任务 |
| 原生应用 | 启动中 | 入口禁用 + 进度 | 等待 |
| 原生应用 | 成功 | 成功通知 | 切换到系统窗口 |
| 原生应用 | 缺失/失败 | 阻断模态框 | 重新检测/重试、关闭 |
| K 线 | 加载中 | 保持图表尺寸的骨架 | 切换标签 |
| K 线 | 可用 | 图表、成交量、数据表 | 缩放、平移、十字线、周期、重置 |
| K 线 | 空/失败 | 空态或错误摘要 | 重新加载数据 |
| Manifest | 无效 | 全屏配置错误，不进入工作台 | 退出应用 |

## 9. 交互与可访问性

### 9.1 控件状态

所有可交互控件必须具备默认、悬停、按下、键盘焦点和禁用状态。焦点环使用 `2px #0B5CAD` 外描边，与组件边缘保持可见间隔。状态变化只调整颜色、边框或透明度，不改变组件尺寸。

过渡时长控制在 `160–200ms`，只用于颜色、透明度和轻微位移；遵循系统“减少动态效果”设置。加载状态不得用持续大面积动画干扰业务阅读。

### 9.2 键盘路径

- `Tab / Shift+Tab` 按视觉顺序移动；当前焦点始终清晰可见。
- `Enter` 提交登录、激活按钮或应用入口；`Space` 激活当前按钮。
- `Esc` 关闭用户菜单、通知或模态框；阻断模态框关闭后焦点回到触发入口。
- 标签支持键盘聚焦与关闭；关闭后焦点移至相邻标签或工作台。
- 图标按钮必须提供中文可访问名称和鼠标工具提示。
- 不在正式界面中长期显示快捷键教学文字。

### 9.3 错误表达

错误必须同时包含图标、标题、简短原因和下一步操作。字段错误贴近字段；模块级错误占据模块内容区；影响继续操作的错误才使用模态框。不得只用红色边框、Toast 或内部错误码表达失败。

## 10. 组件清单

| 组件 | 职责 | 关键约束 |
|---|---|---|
| `AppShell` | 顶栏、状态轨道、侧栏、标签和内容区 | 工作台生命周期内保持稳定 |
| `GlobalHeader` | 产品标识、环境、用户菜单 | 不承载模块操作 |
| `BusinessStatusTrack` | 环境、服务、数据、角色状态 | 单行可扫描；状态带文字 |
| `Sidebar` | 按角色展示授权模块 | 始终显示图标与文字 |
| `TabStrip` | 已打开任务切换 | 工作台固定；同模块单实例 |
| `AppTile` | 工作台模块入口 | 仅用于重复应用项；整块可操作 |
| `WebToolbar` | Web 导航、刷新、来源展示 | 不提供任意 URL 输入 |
| `KlineToolbar` | 标的、价格、周期、重置 | 固定高度，不被动态数字撑开 |

## 11. 界面文案基线

## 12. 分辨率与适配

- 重点验收物理分辨率 `1440×900` 与 `1366×768`，并按麒麟系统 `100% / 125% / 150%` 缩放换算逻辑工作区检查。
- 最低逻辑工作区为 `820×480`；低于该尺寸时限制窗口继续缩小。
- `1100–1279px` 时侧栏降至 `184px`；`820–1099px` 时降至 `168px`。内容边距同步收紧，仍保留菜单文字。
- 短屏模式压缩顶栏、状态轨道和非关键留白，不缩小正文与按钮点击区域。
- 长用户名、角色名、应用名优先单行省略并提供完整工具提示；关键错误与按钮文字必须完整换行显示。
- Web 与 K 线内容使用剩余空间，不通过视口宽度动态放大字号。
- 各固定控件需设置稳定尺寸，避免动态图表数字、进度、悬停或错误文案推动整体布局。
