# 星麒业务工作台 UI 原型验收记录

> 验收日期：2026-07-21  
> 验收结论：**浏览器高保真原型技术验收通过，待业务确认与麒麟真机验收**  
> 验收对象：`mvp-demo/ui-prototype`

## 1. 验收范围

本次验收覆盖高保真浏览器原型的视觉布局、页面状态、角色权限、键盘与焦点、错误恢复、K 线交互、缩放适配和基础可访问性。它用于冻结后续 Qt/QML 实现的 UI 基线，不代表 Qt/QML、QtWebEngine、真实 Web 系统或麒麟本机应用已经完成。

## 4. 本轮修复闭环

| 问题 | 处理结果 |
|---|---|
| Web 与 K 线任务切换后标签丢失 | 已持久化打开标签；支持切换、单实例和关闭后相邻回焦 |
| 加载、空、错误、越界、原生结果和配置错误状态不足 | 已补齐可直接复现的 18 个状态 |
| 125% / 150% 等效视口裁切风险 | 最低逻辑工作区调整为 `820×480`，增加紧凑与短屏布局 |
| 图标按钮和紧凑控件点击区域不足 | 可见按钮与输入统一达到至少 `44×44px` |
| 标签和模态框键盘路径不完整 | 已增加 roving tab、方向键、焦点约束与关闭后回焦 |
| 周 K / 月 K 使用伪周期数据 | 改为基于日 K 的自然周和自然月聚合 |
| 演示来源文案可能被理解为安全背书 | 改为“演示来源”，不声称已完成生产安全校验 |
| 侧栏头像字母对比度不足 | 修正选择器覆盖，文本对比度恢复到 AA 以上 |
| K 线浮层使用英文默认字段 | 改为中文字段，并校验 OHLC 与成交量映射 |

## 5. 尚未覆盖的门禁

以下项目不能由浏览器原型替代，进入正式实现或交付验收前仍需完成：

- 产品/业务确认银行名称、正式标识、角色名称、页面文案和红涨绿跌规则。
- 安全与业务确认正式 Web 名称、URL、Origin 白名单及越界处理策略。
- 验收负责人确认麒麟目标版本、CPU 架构、实际分辨率和 `100% / 125% / 150%` 缩放行为。
- 研发确认 Qt/QML、QtWebEngine、图表方案及 Manifest 的正式实现方式。
- 验收负责人确认本机应用名称、固定可执行路径、参数和成功判定方式。
- 在 ARM64 与/或 x86_64 目标麒麟设备上执行字体、图标、窗口、输入法、屏幕阅读器和启动链路冒烟。
