## 5. 发现问题与修复

| 编号 | 问题 | 根因 | 修复 |
|---|---|---|---|
| UI-01 | 首次服务原型时图标加载报错 | 静态 HTTP 服务禁止跨目录读取 `mvp-demo` 图标 | 将所需 Lucide SVG 与许可证复制进 `ui-prototype/assets/` 并改为本地路径 |
| UI-02 | 打开在线网页后标签栏没有当前任务 | 原型只预置了工作台、自选、个股研究标签 | 新增动态标签创建与激活逻辑，按模块 ID 复用既有标签 |
| UI-03 | 浏览器控制台存在 favicon 404 | 原型未声明 favicon | 使用本地图标作为 SVG favicon |
| UI-04 | 登录成功后仍停留在登录页 | 组件的 `display:grid` 覆盖了 HTML `hidden` 的默认样式 | 增加全局 `[hidden] { display: none !important; }`，以状态属性控制登录页可见性 |
| UI-05 | 原生行情中心的 K 线被挤到可视区下方 | 新增原生状态带后，三行网格没有声明第四个内容轨道 | 将原生行情页明确为状态带、报价头、图表区三轨，并允许图表区占余下空间 |
| UI-06 | Web 内嵌预览只显示首行 | 包含引号的 HTML 直接写进 `srcdoc` 属性，被 HTML 属性解析截断 | 使用脚本设置 iframe `srcdoc`，完整渲染本地演示内容；真实实现仍由 QtWebEngine 按 Manifest 加载 |
| UI-07 | 不同市场模块复用同一曲线和静态数据 | 早期原型只复用一个 K 线数组，周期按钮只更新选中状态 | 以银行指数、宽基、全球、期货、个股、黄金等独立画像生成可重复本地序列；周期切换、缩放和历史窗口实际改变数据根数与时间尺度 |
| UI-08 | 自选表格与详情图的价格尺度不一致 | 类别映射把个股误用为行业指数图表画像 | 建立代码到价格画像的映射，并将各序列最后收盘值归一到表格现价；平安银行显示元级图表，指数显示点位级图表 |
| UI-09 | 市场模块缺少专业行情终端的对象联动 | “表格 + 单图”仅具视觉密度，不具研究工作流 | 新增参考分析文档；自选改为扫描表 + 固定详情研究区，表格行联动报价、盘中走势、区间K线和关联板块；个股/行情/期货重构列入后续阶段 |
| UI-10 | 个股研究仅有单一图表，没有标的池和研究上下文 | 早期页面把图表当成独立展示组件，未建立研究对象状态 | 改为三栏研究工作台：左侧对象池，中部主图/资金/资讯，右侧五档/异动/关联板块；选中对象驱动全页内容 |
| UI-11 | 五档价格出现浮点精度尾数，开高低无业务差异 | 演示数据直接使用 JavaScript 浮点加减，报价头复用了同一价格 | 统一按两位小数格式化五档，并按当前对象价格画像生成开、高、低区间 |
| UI-12 | 市场行情和全球市场沿用自选表格语义 | 早期模块只按标题切换数据，无法表达指数比较和跨时区状态 | 改为独立指数比较工作区：国内显示开高低和交易状态，全球显示美洲/欧洲/亚太会话；右侧以当前指数为上下文联动图表和相关指数 |
| UI-13 | 期货页复用证券名称和证券字段 | 早期六窗格只替换面板标题，数据仍来自证券列表示例 | 改为期货合约与日增仓字段，按交易所/品类分组，选中合约联动期市要闻、图表和关联品种 |

## 6. 已关闭项与下一阶段

1. 市场观察重构已完成：个股研究、国内/全球市场、期货和黄金均已按参考分析建立独立工作区与对象联动，不再复用早期自选表格骨架；证据见第 4 节及 UI-09 至 UI-13。
2. UI 评审已确认模块名称、密度、行情红绿本地化、黄金演示范围与在线网页的“批准配置”表达；真实银行、产品和 Origin 仍属于 T0B 的外部输入，不能由原型推定。
3. 技术方案已评审通过；正式任务拆解见 [任务拆解.md](./任务拆解.md)。实施前按 T0A/T0B 关闭双架构环境与演示内容门禁。
4. 正式实现阶段必须复用原型的结构与状态，并重新验证加载/失败/空状态及 150% 缩放；不能把静态演示行为当作安全能力、真实行情或麒麟兼容性结论。

## 7. 变更留痕规则

后续每一轮 UI 或功能变更必须在本文件补充：变更目标、影响模块、实现方式、验证命令或截图、发现问题及修复结论。涉及范围、交互或数据口径时，同时更新需求分析、UI 规格或技术方案；不能只修改原型代码。
