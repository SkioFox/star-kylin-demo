# V2.1 原型逐页对比与功能验收记录

> 状态：进行中。视觉基准固定为 `原型验收截图/原型版本_V2.1_2026-07-29/`；不能以“应用能启动”代替视觉或功能验收。

## 1. 验收方法

每个模块必须在已安装的同一版本 DEB 上完成以下检查，并归档原始截图：

1. 以 V2.1 同名页面截图比对壳层、配色、字号层级、菜单唯一高亮、标签、面包屑和内容结构。
2. 检查当前模块的默认对象、字段口径、图表类型及内容是否与模块语义相符。
3. 执行模块交互及负向路径；截图仅在交互结果正确后才可标为通过。
4. 分别在 `1280x720`、`1366x768`、`1440x900` 和 150% 缩放复验；不允许页面级滚动、遮挡或竖排压缩。

- 交互：待逐张验证终端、计算器、系统浏览器的启动或“程序缺失”反馈；不绕过 Manifest/C++ 白名单，也不经 Shell 传递会话或凭据。`待操作`。
