# 麒麟工作台集中验证清单

> 状态：开发完成后待执行。适用 `kylin-sky-demo/app/`，参考 `mvp-demo` 的构建、安装和 VM 验证留痕方式。

## 1. 执行边界

- 本清单在全部开发改动冻结后执行；每次内容变更递增 Debian release，不能用同一版本覆盖不同内容。
- 先在同架构构建机完成构建与 CTest，再生成 CPack 未签名基线包；amd64 与 arm64 分别构建、安装和留痕。
- 未强制签名的目标机使用标准 `sudo dpkg -i` 安装基线包。只有目标机明确拒绝时才切换到受信任签名变体；不得关闭系统安全策略或使用 `--no-debsig`。
- 当前 amd64 VM 是预验证环境，不替代客户机；ARM64 结论必须来自原生 ARM64 构建机和真机。

## 2. 构建与自动化测试

```bash
cmake -S ~/kylin-sky-demo-src -B ~/kylin-sky-demo-build \
  -DCMAKE_BUILD_TYPE=Release -DKYLIN_SKY_PACKAGE_RELEASE=<release>
cmake --build ~/kylin-sky-demo-build --parallel 2
ctest --test-dir ~/kylin-sky-demo-build --output-on-failure
```

预期 CTest 项共 8 个：

- `test_resources`：qrc 资源完整性。
- `test_manifest`：Manifest 正反例校验。
- `test_urlpolicy`：导航、资源 Origin、HTTP 降级和路径穿越拒绝。
- `test_marketdata`：fixture 不变量、模型和重载恢复。
- `test_native_launcher`：固定路径、参数上限和缺失程序拒绝。
- `test_appcontroller`：登录、角色、未授权、标签单实例和退出清理。
- `test_klinechart`：日/周/月聚合、缩放和视窗边界。
- `test_qml_load`：Qt 5.12 兼容的 `KlinePanel` QML 加载。

若 KySec 对新的开发二进制首次执行提示本地授权，记录提示与结果；不得把未执行或被安全门禁阻断的测试写成通过。

## 3. 基线包生成与检查

```bash
cd ~/kylin-sky-demo-build
cpack -G DEB
dpkg-deb -f kylin-sky-demo_*.deb Package Version Architecture Depends
dpkg-deb -c kylin-sky-demo_*.deb
sha256sum kylin-sky-demo_*.deb
```

检查包中存在：`/opt/kylin-sky-demo/bin/kylin-sky-demo`、Desktop Entry、图标和 `THIRD_PARTY_NOTICES.md`。`Architecture` 必须等于目标机 `dpkg --print-architecture`。

## 4. amd64/arm64 安装与启动

```bash
sha256sum -c kylin-sky-demo_*.deb.sha256
sudo dpkg -i kylin-sky-demo_*.deb
dpkg-query -W -f='${Package} ${Version} ${Architecture}\n' kylin-sky-demo
/opt/kylin-sky-demo/bin/kylin-sky-demo
```

还须从开始菜单启动“麒麟工作台”，确认启动的进程和版本与已安装包一致。若未签名基线包被目标策略拒绝，记录拒绝信息后使用同版本、同架构的受信任签名变体重试。

## 5. 功能与安全回归

- 登录：`operator / KylinDemo2026`、`auditor / AuditDemo2026`、错误凭证、退出后会话清理。
- 工作台：模块打开、单实例标签、关闭后的相邻回焦、`Esc`、`Delete`/`Ctrl+W`。
- 市场：自选、研究、国内、全球、期货、黄金；研究对象切换后报价、图表和上下文一致。
- 图表：分时/日 K/周 K/月 K、按钮/滚轮/键盘缩放、拖拽、重置和边界文字。
- Web：本地指定业务页、批准 HTTPS 页、刷新、网络错误、越界导航、下载、新窗口、全屏、权限与证书拒绝。
- 网络/Native：检查中、可达、待配置、失败重试；固定程序路径、缺失程序和启动反馈。
- 环境：1366x768、1440x900、150% 缩放、字体、输入法、20 次模块循环与资源基线。
