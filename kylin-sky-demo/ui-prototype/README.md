# 麒麟工作台交互原型

这是 UI 评审物，不是麒麟正式应用、真实 Web 容器或生产行情系统。

## 运行

原型无构建依赖，可直接在浏览器打开 [index.html](./index.html)。需要本地 HTTP 服务时，在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory kylin-sky-demo/ui-prototype
```

访问 `http://127.0.0.1:4173`。

V2.1 科技工作台原型入口为 `http://127.0.0.1:4173/v2.html`。它是当前用于 UI 评审的独立页面，不替换仍保留的 `index.html` 交互基线。

## 已实现的交互

- 左侧导航切换自选、个股研究、行情/全球/期货、黄金业务、指定业务、在线网页、原生行情中心、网络验证和本机应用集成。
- 登录页使用演示账号 `operator / KylinDemo2026` 或 `auditor / AuditDemo2026` 校验用户名和密码；错误凭证原位提示，提交中显示“正在验证”，成功后进入当前工作区。
- 新模块会新增并激活顶部任务标签；已有模块再次打开时只激活既有标签。
- 自选表格行可选中，右侧报价、盘中走势、区间 K 线和关联板块同步更新；各标的使用不同价格尺度和本地演示序列。
- 个股研究与原生行情中心呈现标准 K 线、成交量、MACD、五档或当前蜡烛信息；分时/日K/周K/月K、放大/缩小/重置、滚轮缩放和拖拽历史区间均会改变图表可视数据。
- 黄金业务支持多银行积存金报价对比，选中银行后同步显示当前产品详情和 Au9999 基准趋势。
- 指定业务固定为运营协同系统的受控嵌入预览；在线网页只能从批准配置清单中选择，连续切换后会更新来源与页面内容。
- V2 将每个左侧模块映射到唯一的视图和内容模型：六类市场模块各有默认标的、字段和上下文；指定业务为外汇演示台，在线网页为批准 HTTPS 服务入口，原生行情中心为 Qt 原生能力示意。
- V2 的市场表格支持鼠标、Enter/Space 和上下方向键选择标的；日/周/月周期控件同步更新图表标题、曲线路径和数据视窗说明。

## V2.1 评审重点

- 左侧严格按“市场观察、应用服务、原生能力”三组组织。市场观察的自选、个股研究、市场行情、全球市场、期货观察、黄金业务分别使用扫描/研究/比较/会话/矩阵/双向报价工作区，不再用同一张表和曲线换标题。
- 自选采用可拖动的扫描表与分析区分栏；右侧有分时/均价/量能或日/周/月 K、MACD/资金副图、热点板块和换手信息。个股研究为对象池、主 K 线/MACD/资讯、五档盘口/资金/关联板块三栏布局。
- 内嵌外汇业务展示汇率走势、报价深度和结售汇摘要；在线网页可以在百度与哔哩哔哩两个批准来源间切换。页面仅表达受控容器的 UI，不会发起真实外网请求。
- 网络验证、原生行情中心和本机应用集成沿用一期的功能边界：协议检查、Qt 原生图表工作区、终端/计算器/浏览器启动清单。V2 只改变其视觉语言与布局。
- 顶部标签可关闭，关闭当前标签会回退到前一个仍打开的模块；面包屑仅显示“工作台 / 当前模块”。页面没有全局底部行情条或左侧会话区。

## 范围边界

- 所有报价、资讯、服务状态和网页内容仅供界面演示，不代表真实数据或接口，尤其不代表真实银行黄金报价或交易结果。
- 不包含真实认证、真实页面嵌入、网络请求、系统应用启动或安全策略实现。网页区域使用本地 `iframe srcdoc` 模拟内嵌内容，真实 QtWebEngine 必须按签名 Manifest 加载 `entryUrl`。
- `assets/` 中图标来源于项目既有 Lucide 图标，许可证见 [Lucide-LICENSE.txt](./assets/Lucide-LICENSE.txt)。
- 原型的批准网页配置仅为本地演示。Demo 正式实现使用编译入包的只读 Manifest；签名、审批和回滚属于生产阶段，不由原型实现或暗示。
