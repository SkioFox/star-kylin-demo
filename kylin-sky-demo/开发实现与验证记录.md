## 2026-07-30 客户 amd64 离线安装器兼容性修复

- 客户机运行 `kylin-sky-demo-offline-amd64-0.2.1-5-20260730.1/install.sh` 时，所有 SHA-256 校验通过，两个 WebEngine 依赖也被识别为已安装的精确版本；随后麒麟 APT 在处理应用包时返回 `Internal Error, Pathname to install is not absolute 'kylin-sky-demo_0.2.1-5_amd64.deb'`。
- 根因是该版本将三个本地 DEB 放入同一次 `apt-get --no-download install` 事务。部分客户麒麟 APT 会在依据包名求解后丢失应用 DEB 的绝对路径。这不是应用 DEB 损坏、SHA-256 错误或缺少 WebEngine 依赖。
- 新增离线安装器修订版 `kylin-sky-demo-offline-amd64-0.2.1-5-20260730.2`：应用 DEB 和两个依赖 DEB 保持不变，安装器在既有精确基线检查和 SHA-256 校验后，固定顺序执行 `dpkg --install`。它不连接网络、不调用 `apt --fix-broken install`，也不降低 KySec 或 DEB 签名策略。
- 待客户实机使用 `20260730.2` 完成安装、版本确认、开始菜单/命令行启动和卸载回归后，才能将该问题标记为关闭。

- 后续常规流程改为连续自动执行：SSH 同步、原生构建、静态检查、CTest、CPack、SHA-256、标准安装尝试、已安装版本复核、启动和证据归档均不再逐步等待确认。不得记录或保存 sudo 密码；安全提示、私钥口令和硬件令牌仍由受信任人员操作。
