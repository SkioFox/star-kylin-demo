# 麒麟工作台 UI 设计与原型规格

> 版本：v0.4 ｜ 状态：**V2 科技工作台方向已确认；150% 缩放待正式 QML 阶段复核**
> 适用对象：麒麟桌面上的银行内部柜面、运营与演示人员。

## 1. 设计结论

**方向：银行蓝色的“行情工作台”，不是行情软件的复刻。**

参考图的高信息密度、表格优先和多窗格阅读值得保留；其过密的工具条、强交易语义和独立行情客户端品牌不直接继承。麒麟工作台用稳定的应用外壳承接行情研究、受控 Web 和本机能力，让用户始终知道当前身份、打开了什么、哪些服务可用。

专业行情模块的参考拆解、功能边界和重构顺序见 [行情终端参考分析与重构方向.md](./行情终端参考分析与重构方向.md)。它约束后续原型不再以“同一表格和同一曲线换标题”的方式表达不同市场模块。

设计对象是“银行内部应用集成平台”，单一任务是：**让有权限的员工在一个可恢复的桌面工作区完成发现、打开与切换应用。**

## 2. 视觉计划与自检

### 2.1 令牌

| 名称 | 色值 | 用途 |
|---|---:|---|

| 工作表白 `surface` | `#FFFFFF` | 表格、工具条、内容面 |
| 墨蓝文字 `ink-900` | `#172B42` | 标题、关键数字 |
| 辅助蓝灰 `ink-600` | `#5C6F84` | 时间、次级说明、列标题 |
| 网格线 `line-200` | `#D8E2ED` | 分隔线、表格网格 |
| 身份金 `signal-gold` | `#B98332` | 小面积品牌/重要会话标记 |
| 涨幅红 `market-up` | `#C13D48` | 涨幅、风险增加，须配合 `+` |

字体优先使用 `Noto Sans CJK SC`，回退顺序为 `Source Han Sans SC`、`Microsoft YaHei`、系统 `sans-serif`；报价、百分比、时间与诊断数据优先使用 `Noto Sans Mono`，回退 `monospace`。T0A 必须在两类麒麟机记录实际命中字体、字形覆盖与 DPI。正文 13–14px、模块标题 18px、页面标题 22px；不使用页面级超大标题。

### 2.2 布局和标志性元素

页面采用“**一条工作轨 + 三层工作区**”：顶部工作轨持续呈现会话、网络与打开任务概况；左侧模块栏负责进入；标签栏负责恢复已打开任务；内容区随模块采用表格、图表或 Web 容器。

工作轨不是装饰：它把“身份、权限加载、网络、服务连接和会话剩余时间”压缩为可扫描的状态项。它是本产品相对于普通行情界面的标志性元素，也服务于银行桌面环境中的可追溯感。

**自检结果**：不采用常见的营销卡片、渐变英雄区或四个统计卡。信息密度来自真实的工作任务、表格与上下文面板，蓝色只用于导航、选中和操作，不把页面刷成单一蓝色。

## 3. 信息架构与导航

| 导航分组 | 模块 | 打开形式 |
|---|---|---|
| 我的工作 | 工作台、最近打开 | 固定首页 / 标签激活 |
| 市场观察 | 自选、个股、行情、全球、期货、黄金业务 | 原生标签页 |
| 应用服务 | 指定 Web、在线网页、网络验证 | 独立策略的 Web/原生标签页 |
| 原生能力 | 原生行情中心、本机应用集成 | 原生标签页或独立系统窗口 |

- 左侧栏固定宽度 `216px`，窄屏最小 `188px`，始终保留文字标签。
- 顶部标签固定高度 `42px`，同模块单实例；“工作台”不可关闭。
- 内容页工具条固定 `44px`；状态带固定 `26px`，不随数据刷新跳动。
- 工作区不使用嵌套卡片。卡片仅用于工作台中的重复应用入口，圆角不超过 `6px`。

### P01 登录

```text
│  [金色短线]                  │  麒麟工作台                                  │
│  麒麟工作台                  │  使用工作账号进入                            │
│  统一业务与市场观察入口       │                                               │
│                              │  用户名  [                                ]   │
│  ● 会话与权限统一管理         │  密码    [                                ]   │
│  ● 受控业务系统接入           │                                               │
│  ● 原生行情与工具协同         │  [ 登录工作台 ]                              │
│                              │  登录失败时在此原位说明可修正原因             │
└──────────────────────────────┴───────────────────────────────────────────────┘
```

- 左侧为稳定品牌区，右侧为最大宽度 `420px` 的表单；不使用悬浮卡片。
- 提交后按钮尺寸不变，显示行内进度与“正在验证”。
- 页面可用“演示账号”帮助文本，但不出现“Mock”或真实账户暗示。

### P02 工作台

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 工作台                                             07 月 26 日 · 周日          │
├──────────────────────────────┬───────────────────────────────────────────────┤
│ 常用任务                      │ 最近打开                                      │
│ [ 自选 ] [ 市场概览 ]          │ 个股研究 · 10:22                              │
│ [ 指定业务 ] [ 原生行情中心 ]  │ 指定业务 · 09:48                              │
├──────────────────────────────┴───────────────────────────────────────────────┤
│ 服务状态  行情订阅正常 · 指定业务可用 · 网络验证待执行                         │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 常用任务为紧凑的可点击入口，包含图标、名称、状态和最近使用时间。
- 最近打开是真实任务恢复入口，不放无意义 KPI 卡。
- 服务状态沿用工作轨语义，失败项用图标、文字和“查看”动作表达。

### P04 个股研究与原生行情中心

```text
┌──────────────┬──────────────────────────────────────────┬────────────────────┐
│ 研究对象     │ 当前标的 / 周期 / 缩放                    │ 五档行情           │
│ 平安银行     ├──────────────────────────────────────────┤ 异动详情           │
│ 中证银行     │ 价格 / K 线 / 成交量 / MACD 主分析画布    │ 关联板块           │
│ 沪深 300     ├──────────────────────────────────────────┤                    │
│ 宁德时代     │ 资金与指标            关联资讯            │                    │
└──────────────┴──────────────────────────────────────────┴────────────────────┘
```

- 个股研究采用“标的池 - 主分析画布 - 研究上下文”的三栏结构。左栏切换对象时，中栏报价、图表、资金/资讯和右栏五档/异动/关联板块同步更新。
- 主图采用标准金融 K 线：红涨绿跌蜡烛与影线、MA 叠加线、成交量副图和 MACD 副图；价格、时间和指标标签固定在坐标区，不以颜色单独传达涨跌。
- 原生行情中心是高刷新页面，图表占主视区，不放入装饰卡片。页面以“Qt 原生图表 / 行情流已连接 / 刷新间隔”状态带与 Web 研究页面区分。
- 周期为分段控件；悬停十字线、缩放、拖拽和重置视图均保持图表空间稳定。当前浏览器原型只验证视觉和控件反馈，交互细节在 Qt 实现阶段落地。
- 资讯使用可扫描的时间、来源、标题列表；没有交易、下单或账户文案。

- 主区服务于跨银行比较，统一以人民币元/克显示产品、买入价、卖出价、点差和最近报价；不混入交易、申购、账户或收益承诺。
- 右侧固定为当前银行的产品详情和 `Au9999` 基准趋势。表格行切换时，报价头、说明和选中状态同步更新；周期、缩放、平移作用于基准图。
- “刷新报价”是原型的状态动作。正式实现前必须明确供应商、授权、各银行产品口径、报价延迟和节假日规则；原型数据不应被视为真实银行报价。

### P06 指定 Web 与在线网页

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [后退] [前进] [刷新]  指定业务系统              来源：业务域 · 已受控          │
├──────────────────────────────────────────────────────────────────────────────┤
│ 2px 加载进度条                                                               │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│                         Web 内容区 / 加载失败状态                            │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 不提供地址栏。指定业务固定嵌入“运营协同系统”；在线网页以“已批准页面”选择器切换批准的 Web 配置，而不是输入 URL。
- 每个在线网页配置包含应用名、入口 URL、允许来源、独立 Profile 与 Bridge 权限；原型展示三个批准项，Demo 由编译入包的只读 Manifest 校验，生产阶段再接入签名配置。
- 来源越界、下载、弹窗、证书失败和网络失败均在内容区显示明确状态与“重新加载”或“返回原页面”。
- 外部网页不使用内部 Web 的会话标识；UI 不暗示其可访问行内资源。

### P07 网络验证与本机应用集成

网络验证页以四行固定状态单元展示 `HTTP`、`HTTPS`、`SSE`、`WebSocket`：连接状态、最近结果、耗时和“重试/断开”命令。敏感头、Cookie 和请求正文不在界面呈现。

本机应用集成页只展示已批准工具、路径检查结果与“启动”命令。启动后显示“已请求启动，应用将在独立系统窗口打开”；未安装、策略拒绝和启动失败给出不同原因，不执行 Shell 命令。

## 5. 加载、错误与微交互

| 位置 | 加载设计 | 失败设计 |
|---|---|---|
| 登录 | 按钮内 16px 进度与固定按钮宽度 | 贴近输入框，说明可修正的字段或凭证错误 |
| 表格 | 保留表头与行高的骨架行 | 说明“数据暂不可用”与重试时间，不清空整个工作区 |
| 图表 | 保留坐标区，显示细线扫描与更新时间 | 保留指标工具条，显示“重新加载数据” |
| Web | 2px 顶部进度条 | 内容区状态页，原外壳与其他标签继续可用 |
| 网络 | 每项独立连接动画 | 单项重试，不影响其余协议结果 |

动效只用于按钮反馈、标签切换透明度和加载进度，时长 `160–200ms`；遵循系统减少动态效果设置。没有大面积循环动画、渐变光球或装饰性粒子。

## 6. 可访问性与桌面适配

- 所有可交互元素有默认、悬停、按下、禁用与 `2px` 主操作蓝焦点环。
- `Tab` 在工作轨、侧栏、标签、工具条、数据表与内容区形成稳定顺序；`Enter` 打开模块，方向键在表格和分段控件内移动。
- 1366x768 时右侧上下文区最小 `280px`，资讯可折叠；不裁剪主表格标题或状态带。1440x900 及以上展示完整三栏。
- 最小正文对比度达到 WCAG AA；涨跌和服务状态永远同时包含图标、符号或文字。

## 8. V2 科技工作台重构

### 8.1 目标与风格

V2 服务于麒麟桌面上的银行运营和市场研究人员，核心任务是让用户在市场、受控业务和本机能力间高密度且低干扰地切换。风格升级为“**深色指挥轨 + 冷白数据平面 + 青色信号线**”：科技感来自任务状态、模块信号和数据对齐，不使用营销大图、渐变光球或装饰性粒子。

| 令牌 | 色值 | V2 用途 |
|---|---:|---|
| 指挥深蓝 | `#061B33` | 顶部会话指挥轨、深色导航底座 |
| 导航蓝 | `#0D4F85` | 左侧激活模块、次级深色面 |
| 信号青 | `#00A6C7` | 当前任务脊线、焦点、连接状态 |
| 身份金 | `#D7A84B` | 受控环境、身份与高优先级标记 |
| 冷白画布 | `#F4F8FC` | 主数据平面 |
| 信息墨蓝 | `#17324D` | 标题与报价 |
| 分隔蓝灰 | `#CCD9E6` | 数据网格与层级边界 |

界面字体使用 `Noto Sans CJK SC`，数据使用 `Noto Sans Mono`，均保留系统回退。标题控制在 18–22px；数据、状态和时间使用 11–13px，字距保持默认，不以超大字号制造科技感。

### 8.2 工作区结构

```text
┌ 指挥轨：品牌 / 当前角色 / 环境 / 连接 / 退出 ─────────────────────────────┐
├ 模块栏 ┬ 任务标签轨 ─────────────────────────────────────────────────────┤
│        ├ 信号面包屑：工作台 / 当前模块 / 当前工作上下文                     │
│        ├ 数据工作区：表格、图表、Web 或本机能力                             │
│        └ 状态脊线：来源、更新时间、受控边界                                 │
└────────┴───────────────────────────────────────────────────────────────────┘
```

- 面包屑降为 34px 的细上下文条，只表示真实路径；当前模块使用信号青短线，不能再做成独立的空白工具栏。
- 顶部指挥轨使用紧凑状态胶囊，但不嵌套卡片；“受控环境”和“网络状态”有文字，不仅靠颜色。
- 标签轨使用深浅层级与细底边区分活动任务，关闭操作保持明确且键盘可达。
- 左侧模块栏按真实 `group` 分段，当前模块用导航蓝面和信号青左线标识。

### 8.3 V2 模块规则

- 自选、个股研究、市场行情、全球市场、期货观察、黄金业务进入时默认选择第一个匹配标的；只有数据为空或不可用时显示空/错状态。
- 指定业务使用包内“外汇交易演示台”作为受控 Web 的默认内嵌内容，展示货币对、报价、结售汇请求摘要和风险提示；不连接真实交易、账户或下单能力。
- 在线网页使用同一紧凑 Web 工具条，但明确显示“已批准 HTTPS 来源”，不使用地址栏。
- 原生行情中心在同一页展示本地 Qt K 线示例、周期与缩放控件，以及“启动已批准本机工具”的独立操作和反馈。

### 8.4 V2 验收重点

- 登录后指挥轨、导航、标签、面包屑和首个默认标的均在 1366x768 下无裁切。
- 面包屑、退出、标签和周期控件的文字在默认/悬停/激活状态均可读。
- Web 工具条在加载、失败、拦截时尺寸稳定；下载、新窗口、全屏和证书失败仍被拒绝。
- 原生行情中心的 Qt K 线和本机启动反馈可同时访问，外部工具启动不影响门户进程。

### 8.5 V2 原型状态与布局约束

- 原型导航以一个 `currentModule` 状态驱动：切换时必须先清除所有导航与标签的激活状态，再仅激活目标模块；不能依赖 CSS 叠加制造多重高亮。
- 六类市场模块共用数据工作区的骨架，但必须各自声明默认标的、摘要指标、表格字段口径和右侧详情上下文。期货使用“日增仓”，黄金使用“点差”，不得继续沿用证券“成交额”的语义。
- 指定业务与在线网页共享受控 Web 容器外壳，但必须呈现不同的服务身份、来源和内容。指定业务默认展示包内外汇交易演示台；在线网页默认展示批准 HTTPS 门户。两者都不提供地址栏。
- `html`、`body`、工作区主网格和内容视图均限制为视口高度；滚动仅可出现在确有长内容的内部容器。1366x768 和 1280x720 下不得出现浏览器页面级纵向滚动条或内容遮挡。
- 表格和周期控件的激活态采用浅青数据底色、青色边界和墨蓝文字；不得以黑字、深色边框或与背景对比不足的文本表达选中状态。

### 8.6 V2.1 专业行情工作区

V2.1 以 `origin-ui-refer` 的工作模型作为信息架构输入，而不是复制其品牌、图标、文本或像素布局。核心调整是让“分析画布”成为模块主体，而非在列表右侧附加一张小图。

| 模块 | 主工作区 | 分析区 / 辅助信息 | 禁止复用为 |
|---|---|---|---|
| 自选 | 可滚动扫描表，含标的、现价、涨跌幅、成交额、分类 | 分时/均价/量能与日周月 K 切换、MACD/资金、热点板块 | 单一报价卡或静态装饰图 |
| 个股研究 | 研究对象池 + 当前标的 K 线与周期 | MACD/量能、资讯、五档盘口、资金流、关联板块 | 自选表的简单换标题 |
| 市场行情 | 国内指数与市场宽度比较 | 指数趋势/量能、涨跌家数、热门板块与资金 | 单标的 K 线研究页 |
| 全球市场 | 美洲、欧洲、亚太指数比较 | 跨时区相对走势、会话状态与相关指数 | 国内市场数据的改名版本 |
| 期货观察 | 上期所、郑商所、大商所、能源、金融、外盘矩阵 | 期限结构/量能、期市要闻、关联品种 | 证券名称/成交额字段 |
| 黄金业务 | 银行积存金买入价、卖出价、点差与时间 | Au9999 基准、现货金价差、产品口径说明 | ETF 或期货列表 |

- 右侧或中部分析画布至少包含一个主图和一个可区分的副图；趋势、量能、K 线、MACD、期限结构与双向报价必须按业务语义选择，不能只更改颜色或标题。
- 自选分析区默认将扫描表和分析画布分为约 `48% / 52%`，分隔条可由鼠标拖动调整。列表与二级信息区可内部滚动，根页面不允许出现页面级滚动。
- 标签是可关闭的工作上下文：关闭当前标签后，焦点必须回退到最近的仍打开模块；重复打开模块只激活既有标签，不创建重复实例。
- 左侧只保留市场观察、应用服务、原生能力三个一级分组；取消英文编码和底部会话区。面包屑只显示“工作台 / 当前模块”，取消“上下文”第三层和全局行情底栏。
- 原生行情中心与个股研究的主图必须受可用工作区高度约束：`stage -> layout -> chart` 全链路使用可收缩网格轨；SVG/QML 图表不能以内容最小高度撑开父容器。1280x720 下，原生行情主图最高 360px；个股研究按主 K 线、MACD/量能、资讯的独立轨道分配空间，图表不得覆盖资讯或侧栏。
