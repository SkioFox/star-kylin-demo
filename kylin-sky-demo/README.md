# Kylin Sky Demo

`app/` 是正式 Qt/QML 应用；`ui-prototype/` 仅用于浏览器 UI 评审，不能替代正式程序验证或作为运行时实现。

新成员从[团队协作开发指南](./本机开发指南.md)开始。完成一次环境安装后，在 `app/` 目录执行：

```bash
./tools/local-dev.sh doctor
./tools/local-dev.sh run
```

正式工程内的最短命令说明见 [app/README.md](./app/README.md)。目标麒麟的 DEB、签名和安装边界见[构建安装与签名说明.md](./构建安装与签名说明.md)。
