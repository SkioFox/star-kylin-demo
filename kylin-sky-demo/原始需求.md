设计kylin-sky-demo应用,技术架构参考mvp-demo,目前mvp-demo已经在麒麟虚拟机上跑通验证, 实现一个叫做麒麟工作台的麒麟应用demo:

请根据如下流程完成最终的应用:

1. 需求分析与拆解
2. UI原型设计(包含基础的UI原型设计图, 参考origin-ui-refer列举的示例内容, 最好是有模块基本的交互设计, 最好是有loading设计,loading设计, 文本和内容设计符合实际应用场景) => UI评审
3. 技术方案设计 => 技术方案评审
4. 任务拆分 => 任务评审
5. 功能实现 => 模块功能验证、系统功能验证
6. 应用打包部署麒麟机器 => 应用在麒麟虚拟机上正常运行,功能验证正常
7. 应用及模块性能测试 => 性能测试报告
8. 文档: 设计、开发、测试、验证、修复、部署、使用等各方面文档

有如下模块和功能

  1. 基本的登录功能,用户需要输入用户名和密码,才能登录到应用
  2. 登录后,在应用中有几个模块:自选、个股、行情、全球、期货、内嵌web应用模块、在线网页、QT原生界面模块、黄金...
  3. 内嵌指定web应用模块(权限、安全控制)
  4. 内嵌在线web应用模块(比如打开百度网页、哔哩哔哩视频等)
  5. QT原生界面模块(性能要求比较高、实时的场景、比如做一些实时的图表、动画等,可以做一个炫酷的k线图效果)
  6. 请求发起验证模块:可以进行网络请求(http、https、SSE、websocket等等)
  7. 原生应用集成台模块: 应用可以拉起其他原生应用 => 比如打开终端、原生计算器、浏览器

涉及的数据均使用mock数据,选择合适的方式进行请求获取(比如web应用通过mock http请求, 原生应用选择合适的数据获取方式),但是不要在应用里面体现mock相关字样,只是数据是mock即可.
